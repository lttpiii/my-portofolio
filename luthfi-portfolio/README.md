# Luthfi Indrawan — Portfolio Website

Modern personal portfolio website built with React, Tailwind CSS, and Framer Motion.

## ✨ Features

- Modern responsive UI
- Smooth scrolling navigation
- Animated sections using Framer Motion
- Dark / Light mode
- Interactive project showcase
- CV page
- Social & contact integration
- Mobile friendly
- Clean and scalable component structure

---

## 🚀 Tech Stack

### Frontend

- React
- React Router DOM
- Tailwind CSS
- Framer Motion
- Lucide React
- React Icons
- Vite

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/lttpiii/your-repository.git
```

Go to project directory:

```bash
cd your-repository
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

---

## 🛠 Build

Production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
